# System Design Live Lectures

Whiteboard notes, Java examples, live-coding exercises, and quizzes for
learning Low-Level Design (LLD).

## Lectures

### 01: Introduction to LLD

- [Whiteboard notes](Lecture-01-Intro-to-LLD/Lecture-01-Whiteboard.excalidraw)
- [Food-ordering example](Lecture-01-Intro-to-LLD/code/src/com/foodapp)
- [Live-coding exercises](Lecture-01-Intro-to-LLD/code/live)
- [Quizzes](Lecture-01-Intro-to-LLD/code/src/com/foodapp/quiz)

Topics include LLD vs. HLD and DSA, classes and objects, constructors,
access modifiers, encapsulation, `static`, `final`, enums, and packages.

## Using the material

Open [Excalidraw](https://excalidraw.com) and use **Open** to load the
downloaded whiteboard file.

For the Java examples, install a JDK (Java 11 or newer). Open the
lecture's `code` folder in VS Code with the Extension Pack for Java.
The included build task compiles the main example and quizzes; the
**Food app (Main)** launch configuration runs the food-ordering example.
The `live` folder contains practice exercises that may be incomplete
during a lecture.
